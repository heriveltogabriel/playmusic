Integração com o Discogs

Configuração do catálogo, busca de lançamentos e importação de coleções.

Como obter o Token do Discogs:
  1. Faça login no Discogs.
  2. Acesse a página de Configurações de Desenvolvedor.
  3. Clique no botão "Generate new token", copie o token gerado e cole no campo acima.

Reconhecimento Shazam (RapidAPI)

Opção alternativa / de backup para reconhecimento de áudio usando a API do Shazam via RapidAPI.

Como obter a Chave da RapidAPI:
  1. Faça login na RapidAPI.
  2. Inscreva-se na API Shazam ou Shazam Core.
  3. Na aba Endpoints de teste, copie o valor do campo X-RapidAPI-Key e cole no campo acima.

Sincronização de Letras

Ajuste da sincronização de tempo para as legendas em relação ao áudio reproduzido.

O padrão recomendado é **1.3** segundos. Aumente o valor para adiantar as letras (ex: 5.0 ou 10.0) ou diminua para atrasá-las.
